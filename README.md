# idol-map

Radiooooo ミミック：**日本の御当地アイドルを「地方 × 年代」で選んで音楽へアクセス**。

## コンセプト
- Radiooooo の「場所と時代ごとに音楽にアクセスする」を、日本の**御当地アイドル**に適用。
- 地方（8ブロック）と年代（1970–2030）を選ぶと、その地域の御当地アイドルを
  YouTube 検索で再生し、あわせてその時代の「アイドル民俗学」コンテキストを表示。

## データ
- 年代コンテンツ（アイドル民俗学）は [`bonsai/idol-quiz`](https://github.com/bonsai/idol-quiz) の
  「アイドル民俗学検定」から借用。
- 地域軸（地方）は `data.js` の `regions` に定義。
- 地域ごとの実アイドルデータは `data.js` の `localIdols` に追加可能（現状は空のシード）。

## 使い方
静的サイトなので `index.html` をブラウザで開くだけ。
1. 地方を選ぶ
2. 年代を選ぶ
3. 「▶ この地域の御当地アイドルを再生」で YouTube 検索が開く

## 拡張
`data.js` の `localIdols` に `{ region, decade, name }` を追加すると、
その地域・年代にピンが表示され、直接そのアイドル名で検索できます。
